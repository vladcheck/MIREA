# ГОСТ 2.710-81 для ПР1 — рабочая выписка

Источник: ru.wikisource.org/wiki/ГОСТ_2.710—81 (текст стандарта, издание 2007 с Изм. №1),
первоисточник: docs.cntd.ru/document/1200001985. Статус действующий (vsegost.com).

## Что регулирует
- Только буквенно-цифровые обозначения элементов/устройств/групп и правила их
  построения. Не задаёт графику символов (это ГОСТ 2.721–2.768) и не задаёт
  правила выполнения схем (это ГОСТ 2.702-2011).
- Позиционное обозначение — обязательное (п.1.2): вид + номер, функция —
  необязательна (п.2.2.11). Пример: `C41` (C4 как интегрирующий).
- Одной буквой — общий код группы, двумя — уточнение вида (п.2.2.12). Первая
  буква двухбуквенного кода = группе. Пояснения кодов — на поле схемы.
- Запись в одну строку без пробелов, прописные латиница + цифры (п.2.1–2.2.1).
- N01–N25 в ПР1 — дополнительное обозначение по п.1.2, пояснено таблицей цепей
  на поле схемы и в OTCHET.md. Допустимо.

## Применённые коды (табл.1, 2 обязательного прил.1)
| Код | Группа / вид | Наш элемент |
|---|---|---|
| D / DD | Схемы интегральные / цифровая | DD1 = STM32F100C8Tx (бывш. U1) |
| H / HG | Индикационные / символьный | HG1 = KCSC02-105 (бывш. U2) |
| H / HL | Индикационные / световая сигнализация | HL1–HL8 (бывш. LED1–8) |
| S / SB | Коммутационные / кнопочный | SB1–SB4 (бывш. S1–S4) |
| R / RP | Резисторы / потенциометр | RP1 (бывш. RV1) |
| R | Резисторы | R1–R18 без изменений |
| C | Конденсаторы | C1–C4 без изменений |

`U`, `LED`, `RV`, `S` без второй буквы — не из ГОСТ 2.710 (это IEC/вендорные
коды KiCad по умолчанию). Оставлены только generic-имена библиотечных символов
(`Device:LED`, `Switch:SW_SPDT`), позиционные обозначения исправлены.

## Проверки
- `kicad-cli sch erc --severity-all PR1_KiCad.kicad_sch` → 0 ошибок.
- `.opencode/skills/kicad/scripts/analyze_schematic.py` — эвристика, даёт
  ложные срабатывания по силовым цепям (сливает +3V3/GND через PWR_FLAG в одну
  сеть: C2/C3 «закорочены», R10 «без pull-down»). ERC — истина.
- Переименование выполнено скриптом точной замены `"U1"→"DD1"` и т.д. +
  метки `LED→HL`, `SW→SB`, тексты таблицы N03–N10/N19–N22, бэкап
  `PR1_KiCad.kicad_sch.bak_gost`.
