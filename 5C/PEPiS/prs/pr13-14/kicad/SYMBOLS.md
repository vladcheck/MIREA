# Происхождение символов схемы ПР 13-14

Все символы встраиваются в `lib_symbols` листов (`adc_investigation.kicad_sch`,
`mcu_connection.kicad_sch`), потому что на машине разработки нет глобальной
таблицы библиотек KiCad — kicad-cli разрешает символы только из самого листа
(тот же приём, что в pr7-8). Электрически встроенные копии идентичны
исходникам; изменения касаются только оформления (скрытые номера выводов
у многовыводных корпусов).

## Собственные символы (библиотека проекта pr1314, tools/make_schematic.py)

- **VIRT_ADC16** — виртуальный 16-разрядный АЦП (Vin, Vref+, Vref-, SOC,
  OE, EOC, D15..D0). Собственный символ **обязателен**: в ТЗ (лабораторная
  работа № 7) АЦП — виртуальный прибор из группы Mixed Multisim, аналога
  нет ни в одной стандартной библиотеке KiCad.
- **VIRT_DAC16** — виртуальный 16-разрядный ЦАП (D15..D0, Vout). Также
  виртуальный прибор Multisim из ТЗ — custom только.
- **PROBE** — логический пробник-индикатор (аналог виртуального пробника
  Multisim/Proteus), вспомогательный символ для наглядности схемы.
- **INV1** — инвертор 74LS04 (элемент A), используется для формирования
  OE в противофазе SOC.

## Встроенные копии системных библиотек KiCad

- **Simulation_SPICE** (`Simulation_SPICE.kicad_sym`): VDC (V1, V2, V3 —
  источники постоянного напряжения), VPULSE (V4 — синхронизация 1 кГц),
  VOLTMETER_DIFF (U1 — вольтметр на выходе ЦАП).
- **power** (`power.kicad_sym`): GND, +5V, PWR_FLAG — силовые символы.
- **MCU_Microchip_8051** (`MCU_Microchip_8051.kicad_sym`): AT89x51xxP
  (U1 — микроконтроллер AT89C51, лист 2).

Генератор: `python3 tools/make_schematic.py` (пересоздаёт проект и листы).
