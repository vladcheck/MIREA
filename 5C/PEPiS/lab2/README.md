# Лабораторная работа #2 — Управление семисегментным индикатором (STM32F407VGT6)

Лабораторная работа по дисциплине «Программирование электронных приборов и систем»
(МИРЭА — РТУ): статическая и динамическая (мультиплексная) индикация на
четырёхразрядном семисегментном индикаторе с общим катодом, прямой (bare-metal)
доступ к регистрам CMSIS, сборка средствами PlatformIO.

Вариант 4: статическая цифра «4»; динамический год 2026 ↔ год рождения;
точка во втором разряде; счётчик секунд.

## Требуемое ПО

- **VS Code** + расширение **PlatformIO IDE** (или PlatformIO Core CLI)
- Для прошивки: инструменты `stlink` — `brew install stlink` (macOS)
- Никакие дополнительные библиотеки не нужны, используется только фреймворк `stm32cube`

Если команда `pio` не находится в PATH, используйте панель PlatformIO в VS Code
(кнопки Build / Upload) либо:

```bash
export PATH="$HOME/.platformio/penv/bin:$PATH"
```

## Как запустить каждую задачу

Из этой папки (`lab2/`):

```bash
pio run -e static    # Статическая цифра «4»
pio run -e dynamic   # Динамический год 2026
pio run -e switch    # Задание 5.1: переключение по S1
pio run -e dot       # Задание 5.2: год с точкой «20.26»
pio run -e counter   # Задание 5.3: счётчик секунд
```

или собрать всё сразу:

```bash
pio run -e static -e dynamic -e switch -e dot -e counter
```

Готовая прошивка — файл `.pio/build/<окружение>/firmware.bin` (и `.elf`).

### Прошивка (нужна плата + программатор ST-LINK)

```bash
brew install stlink   # один раз
st-flash write .pio/build/dynamic/firmware.bin 0x8000000
```

или через PlatformIO:

```bash
pio run -e dynamic -t upload
```

## Подключение

- Сегменты индикатора **a–g, dp** → выводы **PA0–PA7** порта GPIOA
  (PA0 — a, …, PA6 — g, PA7 — dp), через токоограничивающие резисторы
  270 Ом (общие для всех разрядов — допустимо в динамическом режиме)
- Общие катоды разрядов **CC1–CC4** → выводы **PC0–PC3** порта GPIOC
  (CC1 — DIG1/тысячи, …, CC4 — DIG4/единицы), активный низкий уровень
- Кнопка **S1**: вывод **PB0** → GND; на PB0 включена внутренняя подтяжка
  к питанию (ненажата — «1», нажата — «0»)

```
              STM32F407VGT6
PA0 --[R1 270 Ом]--+-- a (все 4 разряда)
...                +-- ...
PA7 --[R8 270 Ом]--+-- dp
PC0 ----------------- CC1 (DIG1, тысячи)
PC1 ----------------- CC2 (DIG2, сотни)
PC2 ----------------- CC3 (DIG3, десятки)
PC3 ----------------- CC4 (DIG4, единицы)
PB0 ----[S1]---- GND
```

Индикатор с общим катодом: сегмент горит при «1» на PAx, разряд выбран
при «0» на PCx.

## Что делает каждая программа

| Окружение | Файл | Поведение |
|---|---|---|
| `static` | `main_static.c` | Код `digit_code[4]` на PA0–PA6, катод PC0 = «0» |
| `dynamic` | `main_dynamic.c` | Мультиплекс `{2,0,2,6}`: гашение всех катодов → код → `BRR` разряда, `delay(1500)` |
| `switch` | `main_switch.c` | То же + опрос PB0 с антидребезгом (50 чтений): отпущена — 2026, нажата — год рождения |
| `dot` | `main_dot.c` | То же + бит `0x80` (PA7) в разряде pos = 1 → «20.26» |
| `counter` | `main_counter.c` | `split_digits()` + мультиплекс; +1 каждую секунду (калиброванная задержка) |

Общая init-часть: `RCC->AHB1ENR |= GPIOAEN/GPIOBEN/GPIOCEN`, сегменты и катоды —
выходы push-pull / низкая скорость / без подтяжек (`MODER/OTYPER/OSPEEDR/PUPDR`),
кнопка — вход с pull-up.

## Схема подключения

Файл KiCad: `schematic/lab2-7seg.kicad_sch` (KiCad 10, все символы встроены
в файл — внешние библиотеки не нужны):

- `U1` — STM32F407VGT6 (тот же символ, что в ЛР № 1);
- `HG1` — Kingbright CC56-12GWA, 4-разрядный индикатор с общим катодом
  (штатный символ KiCad `Display_Character`);
- `R1–R8` — 270 Ом, 0805;
- `S1` — кнопка (штатный символ KiCad `Switch:SW_Push`).

Проверка: `kicad-cli sch erc` — **0 ошибок, 0 предупреждений**
(как и в ЛР № 1); список цепей подтверждает соответствие схеме коду.
