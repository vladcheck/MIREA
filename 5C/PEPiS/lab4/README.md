# Лабораторная работа #4 — Стенд МПСУ-Ш-МН, программирование ATmega32 на языке Си

Лабораторная работа по дисциплине «Программирование электронных приборов и систем»
(МИРЭА — РТУ): знакомство со стендом МПСУ-Ш-МН, простейший цифровой ввод вывод
и комбинационные и последовательностные узлы на микроконтроллере ATmega32,
программирование на языке Си (avr-gcc, avr-libc), сборка средствами PlatformIO.

Вариант 4: дешифратор PD2:PD1 в PD4-PD7 (00 в 0x10, 01 в 0x20, 10 в 0x40,
11 в 0x80); элемент 4ИЛИ; JK триггер; дополнительный код; конъюнкция тетрад.

## Требуемое ПО

- **VS Code** + расширение **PlatformIO IDE** (или PlatformIO Core CLI)
- Для прошивки стенда: штатный программатор AVR JTAG ICE через USB
  (в методичке описан через AVR Studio, здесь сборка через PlatformIO)
- Никакие дополнительные библиотеки не нужны, используется только avr-libc

Платформа `atmelavr` ставится один раз:

```bash
pio platform install atmelavr
```

## Как запустить каждую задачу

Из этой папки (`lab4/`):

```bash
pio run -e example1   # Учебный пример 1
pio run -e example2   # Учебный пример 2
pio run -e variant4   # Задача 3, вариант 4
pio run -e jk         # Задача 5г, JK триггер
pio run -e traffic    # Задача 12, светофор
```

или собрать всё сразу:

```bash
pio run
```

Готовая прошивка — файл `.pio/build/<окружение>/firmware.hex` (и `.elf`).
Все 15 окружений собираются без предупреждений (`-Wall -Wextra` чист).

## Подключение (стенд МПСУ-Ш-МН)

- Входы **PA0-PA7** — тумблеры SA1-SA8 (замыкание на GND, активный низкий,
  в прошивках с кнопками включены подтяжки и программная инверсия)
- Входы **PB0-PB3** — кнопки SB1-SB4 на GND (задача 2 использует PB0,
  задача 8 тетраду PB0-PB3)
- Выходы **PC0-PC7** — через резисторы 1 кОм на светодиоды VD1-VD8 (активная 1)
- Выходы **PD0-PD7** — через резисторы 1 кОм на светодиоды VD9-VD16;
  в варианте 4 биты **PD1, PD2** одновременно входы с кнопок SB5, SB6
- Питание 5 В, кварц 8 МГц, сброс через кнопку на GND

## Примеры из методички и их перенос на avr-gcc

Методичка приводит программы для компилятора ImageCraft ICCAVR.
Соответствие использованных средств:

| ImageCraft | avr-gcc | Назначение |
|---|---|---|
| `iom32v.h` | `avr/io.h` | описания регистров ATmega32 |
| макросы `CLI` и `SEI` | функции `cli` и `sei` | запрет и разрешение прерываний |
| `void main` | `int main` | точка входа программы |

## Задержки примера 2 (задачи 9–11)

Базовый пустой цикл `for (i = LOOP_START; i; i++) {}` при `LOOP_START = 1`
даёт 65535 итераций. Время посчитано по дизассемблированному коду
(`avr-objdump`, тактирование 8 МГц): одна итерация занимает 19 тактов,
приём тот же, что секундомер симулятора AVR Studio из задач 9 и 11.

| Конфигурация | `LOOP_START` | `LOOP_REPEAT` | Время |
|---|---|---|---|
| База, задание 9 (`example2`) | 1 | 1 | около 155,65 мс |
| Задача 10а (`delay_half`) | 32768 | 1 | около 77,83 мс |
| Задача 10б (`delay_x4`) | 1 | 4 | около 622,60 мс |
| Задача 11г, вариант 4 (`delay_05s`) | 12904 | 4 | около 500,02 мс |

Важно: счётчики цикла объявлены `volatile`. Без этого оптимизатор avr-gcc
полностью удаляет пустой цикл (проверено по дизассемблированному коду:
`main` сводился к чтению, сдвигу и записи `PORTD` без паузы), и вместо
бегущего огня получается переключение за единицы микросекунд.
