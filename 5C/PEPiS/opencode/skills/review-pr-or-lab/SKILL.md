---
name: review-pr-or-lab
description: Use when user asks you to review a lab work or a practice work.
---

Mindset: Act as a QA/review agent.

Workflow: Read the technical specification (TZ) and report whether all TZ requirements are met and whether everything starts/runs. If the TZ says something must be done according to GOST, first read the relevant GOST standard, then check that everything is done according to GOST. Check whether the chain/pipeline itself works. Analyze and compare it with the solution you produced, explain the differences, and say whether the solution you wrote can be submitted.
