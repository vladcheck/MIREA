# Лабораторная работа №3 — Генератор логических уровней

Плата: STM32F4DISCOVERY (STM32F407VGT6), фреймворк STM32Cube, прямой доступ к регистрам (CMSIS).
Индивидуальный вариант: **4**.

Сборка и загрузка отдельного примера:

```bash
pio run -e <среда> -t upload
```

## Назначение сред (программ)

### `led` — учебный пример 2.2: свитч → светодиод
Источник: `src/main_led.c`

- **PB8** — вход с подтяжкой вверх, подключён к свитчу.
- **PA0** — выход, подключён к светодиоду.
- Логика: пока свитч замкнут (на PB8 низкий уровень), светодиод горит; свитч разомкнут — светодиод погашен.

### `display` — учебный пример 3.2: код SW1–SW4 на двухразрядном индикаторе
Источник: `src/main_display.c`

- **PB8–PB11** — входы свитчей S1–S4 (подтяжка вверх, активный низкий).
- **PA0–PA6** — сегменты a–g семисегментного индикатора (1 = сегмент горит).
- **PC0, PC1** — катоды двух разрядов (0 = разряд включён).
- На индикаторе в виде числа 0–15 отображается двоичный код замкнутых свитчей
  (S1 = 1, S2 = 2, S3 = 4, S4 = 8). Опрос с дебаунсом: 6 подряд совпадающих
  отсчётов с периодом 2 мс (~12 мс стабильности).

### `toggle` — задание 1: переключатель-инвертор с дебаунсом
Источник: `src/main_toggle.c`

- **PB8** — вход кнопки/свитча (подтяжка вверх, нажатие — низкий уровень).
- **PA0** — выход на светодиод.
- Каждое устойчивое нажатие (дебаунс 6 × 2 мс) переключает состояние
  светодиода на противоположное; светодиод остаётся в новом состоянии после
  отпускания (триггер-инвертор).

### `modes` — задание 2: режимы свечения LED по SW1 + SW2
Источник: `src/main_modes.c`

- **PB8, PB9** — входы свитчей S1, S2 (подтяжка вверх, активный низкий).
- **PA0** — выход на светодиод.
- Режим выбирается кодом замкнутых свитчей (устойчивый код после дебаунса 6 × 2 мс):

| S1 | S2 | Код | Режим |
|----|----|-----|-------|
| разомкн. | разомкн. | 00 | светодиод выключен |
| замкн.   | разомкн. | 01 | мигание медленное (полупериод 500 мс) |
| разомкн. | замкн.   | 10 | мигание быстрое (полупериод 125 мс) |
| замкн.   | замкн.   | 11 | светодиод включён постоянно |

### `counter` — задание 3: счётчик нажатий 0–9
Источник: `src/main_counter.c`

- **PB8** — вход кнопки (подтяжка вверх, нажатие — низкий уровень).
- **PA0–PA6** — сегменты a–g; **PC0, PC1** — катоды двух разрядов.
- Каждое устойчивое нажатие (дебаунс 6 × 2 мс) увеличивает счётчик на 1,
  после 9 — сброс на 0. На индикаторе отображается текущее значение
  (десятки всегда 0, единицы — счётчик), мультиплексирование с периодом 2 мс.

### `binary4` — задание 4 (вариант 4): динамическое отображение S1–S4 на четырёх разрядах
Источник: `src/main_binary4.c`

- **PB8–PB11** — входы свитчей S1–S4 (подтяжка вверх, активный низкий).
- **PA0–PA6** — сегменты a–g; **PC0–PC3** — катоды четырёх разрядов
  (DIG1 слева — PC0 … DIG4 справа — PC3).
- Четыре свитча показаны одновременно на четырёх разрядах: на каждом разряде
  горит цифра 0 или 1 в зависимости от состояния соответствующего свитча
  (S1 → DIG1 … S4 → DIG4). Дебаунс 6 × 2 мс, мультиплексирование 2 мс.

## Схема подключения (внешняя, общая для всех программ)

| Сигнал | Вывод STM32 | Направление | Примечание |
|--------|-------------|-------------|------------|
| S1–S4  | PB8–PB11    | вход, pull-up | активный низкий |
| a–g    | PA0–PA6     | выход, push-pull | 1 = сегмент горит |
| DIG1–DIG4 | PC0–PC3 | выход | общий катод, активный низкий |
| LED    | PA0         | выход, push-pull | 1 = светодиод горит |
