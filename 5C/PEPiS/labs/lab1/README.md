# Лабораторная работа #1 - Основы работы с GPIO (STM32F407VGT6)

Лабораторная работа по дисциплине "Программирование электронных приборов и систем" (МИРЭА - РТУ):
прямое (bare-metal) управление портами GPIO микроконтроллера STM32F407VGT6
(отладочная плата ST STM32F4DISCOVERY) через регистры CMSIS, сборка средствами PlatformIO.

## Требуемое ПО

- **VS Code** + расширение **PlatformIO IDE** (или PlatformIO Core CLI)
- Для прошивки: инструменты `stlink` - `brew install stlink` (macOS)
- Никакие дополнительные библиотеки не нужны, используется только фреймворк `stm32cube`

Если команда `pio` не находится в PATH, используйте панель PlatformIO в VS Code
(кнопки Build / Upload) либо:

```bash
export PATH="$HOME/.platformio/penv/bin:$PATH"
```

## Структура проекта

```
lab1-gpio/
├── platformio.ini      # 5 сборочных окружений (по одному на каждую задачу)
├── src/
│   ├── main_blink.c        # Задача: мигание одного светодиода на PA0
│   ├── main_running.c      # Задача: бегущий огонь PA0 -> PA3
│   ├── main_reverse.c      # Самостоятельная задача 1: бегущий огонь PA3 -> PA0 (обратно)
│   ├── main_bounce.c       # Самостоятельная задача 2: двусторонняя мигалка, центр <-> края
│   └── main_fast.c         # Самостоятельная задача 3: бегущий огонь, увеличенная скорость
├── schematic/
│   └── lab1-gpio.kicad_sch # Схема подключения светодиодов (KiCad 7/8)
└── README.md
```

Плата: `disco_f407vg` (STM32F407VGT6, 168 МГц). Каждое окружение компилирует
ровно один файл `main_*.c` через `build_src_filter`, поэтому все задачи
совмещаются в одном проекте.

## Как запустить каждую задачу

### 1. Сборка

Из этой папки (`microcontrollers/lab1-gpio/`):

```bash
pio run -e blink           # Задача: мигание одного светодиода (PA0)
pio run -e running_light   # Задача: бегущий огонь PA0 -> PA3
pio run -e running_reverse # Самост. задача 1: обратный бегущий огонь PA3 -> PA0
pio run -e running_bounce  # Самост. задача 2: центр <-> края
pio run -e running_fast    # Самост. задача 3: быстрый бегущий огонь
```

или собрать всё сразу:

```bash
pio run
```

Готовая прошивка - файл `.pio/build/<окружение>/firmware.bin` (и `.elf`).

### 2. Прошивка (нужна плата + программатор ST-LINK)

```bash
brew install stlink   # один раз
st-flash write .pio/build/running_light/firmware.bin 0x8000000
```

или через PlatformIO:

```bash
pio run -e running_light -t upload
```

### 3. Подключение (на стенде "Учтех-Профи" или на плате Discovery)

- Подключить светодиоды к выводам **PA0-PA3** порта GPIOA (для задач с бегущим огнём)
  или только к **PA0** (для задачи мигания)
- Каждый светодиод подключается через токоограничивающий резистор (~270 Ом при 3.3 В, 5 мА)
- Уточнить активный уровень светодиодов (активный высокий HIGH или активный низкий LOW)
  и при необходимости изменить шаблоны (pattern) в коде

## Что делает каждая программа

| Окружение | Файл | Поведение |
|---|---|---|
| `blink` | `main_blink.c` | Переключение PA0 атомарными записями в `BSRR`, `delay(300000)` |
| `running_light` | `main_running.c` | `pattern <<= 1` по PA0-PA3, запись в ODR с маской `0xFFF0` |
| `running_reverse` | `main_reverse.c` | То же, но `pattern >>= 1`, старт и возврат к `0x08` (PA3) |
| `running_bounce` | `main_bounce.c` | Чередование `0b0110` (PA1+PA2, центр) и `0b1001` (PA0+PA3, края) |
| `running_fast` | `main_fast.c` | То же, что running_light, но `DELAY_COUNT 50000` вместо `200000` |

Общая init-часть в каждом файле: `RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN`,
затем PA0-PA3 настраиваются как выходы push-pull / низкая скорость / без подтяжек
через регистры `MODER/OTYPER/OSPEEDR/PUPDR`.

## Схема подключения

Файл KiCad: `schematic/lab1-gpio.kicad_sch` (открывается в KiCad 7/8, внешние
библиотеки не нужны - все символы встроены в файл).

```
        STM32F407VGT6 (GPIOA)
PA0 ----[R1 270 Ом]----|>|---- GND
PA1 ----[R2 270 Ом]----|>|---- GND
PA2 ----[R3 270 Ом]----|>|---- GND
PA3 ----[R4 270 Ом]----|>|---- GND
```

Каждая цепочка: вывод PAx -> токоограничивающий резистор 270 Ом -> светодиод
(анодом к резистору) -> GND. Светодиод горит при логической "1" на выводе
(активный высокий уровень, source).

Если светодиоды стенда активны низким уровнем (sink), схема зеркальная:
аноды светодиодов -> 3V3, катоды -> резистор -> вывод PAx; тогда светодиод
горит при логическом "0". Для задачи blink достаточно одной цепочки (PA0).

## Отличия от методических указаний (сознательные исправления)

- Граница цикла настройки выводов: `i < 3` заменено на `i < 4`
  (в примере методички для F407 настраиваются только PA0-PA2, хотя в тексте сказано PA0-PA3)
- Маска для ODR: `0xFF00` заменена на `0xFFF0`
  (используются только PA0-PA3; маска из методички портила бы состояние PA4-PA7)
