# Лабораторная работа № 4 (редакция v2)

**Тема:** работа с матричной клавиатурой и графическим дисплеем на базе ATmega32.

Стенд МПСУ-Ш-МН, ATmega32, тактирование 8 МГц (внешний кварц), язык Си
(avr-gcc, avr-libc), без Arduino Framework. Прошивка — встроенный
программатор стенда (классический AVR JTAG ICE serial через FT232R USB-UART).

Методические указания: `docs/sources/ЛР_4_ATmega32_методические_указания_v2.pdf`.

## Схема подключения

### Таблица 1. Матричная клавиатура 4×4 → ATmega32

| Элемент стенда | Вывод клавиатуры | Вывод ATmega32 |
| -------------- | ---------------- | -------------- |
| Строка 0       | X0               | PB0            |
| Строка 1       | X1               | PB1            |
| Строка 2       | X2               | PB2            |
| Строка 3       | X3               | PB3            |
| Столбец 0      | Y0               | PB4            |
| Столбец 1      | Y1               | PB5            |
| Столбец 2      | Y2               | PB6            |
| Столбец 3      | Y3               | PB7            |

Строки X0–X3 — выходы, поочерёдно переводятся в «0»; столбцы Y0–Y3 — входы
с внутренней подтяжкой вверх (pull-up).

> **Примечание (фактическая коммутация стенда).** На стенде группы X и Y
> подключены к PORTB наоборот относительно таблицы 1: Y0–Y3 сидят на
> PB0–PB3, а X0–X3 — на PB4–PB7. Прошивка адаптирована под фактическую
> коммутацию (сканируются PB0–PB3, опрашиваются PB4–PB7, индексы keymap
> переставлены), перекладывать провода не нужно.

### Таблица 2. Графический дисплей 128×64 (KS0108) → ATmega32

| Элемент стенда        | Вывод дисплея | Вывод ATmega32 |
| --------------------- | ------------- | -------------- |
| Линия данных 0        | DB0           | PA0            |
| Линия данных 1        | DB1           | PA1            |
| Линия данных 2        | DB2           | PA2            |
| Линия данных 3        | DB3           | PA3            |
| Линия данных 4        | DB4           | PA4            |
| Линия данных 5        | DB5           | PA5            |
| Линия данных 6        | DB6           | PA6            |
| Линия данных 7        | DB7           | PA7            |
| Выбор левой половины  | CS1           | PD0            |
| Выбор правой половины | CS2           | PD1            |
| Аппаратный сброс      | RST           | PD2            |
| Режим чтение/запись   | R/W           | PD3            |
| Команда/данные        | D/I           | PD4            |
| Разрешение передачи   | E             | PD5            |

PORTC не используется (часть линий занята аппаратным JTAG).

## Логика основной программы (src/main.c)

- Поле `KEY:` (page 0) — символ последней нажатой клавиши.
- Поле `BUF:` (page 2) — строка введённых символов (максимум 16).
- Подсказка `A CLR B BS` (page 6).
- Клавиша **A** очищает BUF, **B** удаляет последний символ,
  остальные символы добавляются в BUF.
- Сканирование клавиатуры с программным подавлением дребезга (20 мс),
  событие формируется по фронту нажатия (удержание не повторяет символ).

## Задания на самостоятельную работу (п. 11 методички)

| Файл             | Задание                                                                          |
| ---------------- | -------------------------------------------------------------------------------- |
| `src/11a_main.c` | Клавиша C очищает только поле KEY, не трогая BUF                                 |
| `src/11b_main.c` | Клавиша D добавляет в BUF символ «-» вместо D                                    |
| `src/11c_main.c` | Счётчик нажатий 0–99 на строке page 4 (CNT), после 99 — снова 0                  |
| `src/11d_main.c` | BUF максимум 10 символов; 11-й → сообщение FULL (page 3), ввод игнорируется до A |

## Сборка и прошивка

```bash
cd labs/lab4
pio run                              # все окружения
pio run -e ATmega32                  # только основная программа
pio run -e ATmega32 -t upload        # прошивка основной программы
pio run -e 11a -t upload             # прошивка задания 11а
# аналогично: -e 11b, -e 11c, -e 11d
```
