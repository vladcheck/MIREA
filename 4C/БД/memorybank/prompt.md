Язык `plpgsql`
Во всех строковых значениях в таблицах обязательно должна содержаться фамилия `valekzhanin` через нижнее подчеркивание, например вместо `brick` будет `brick_valekzhanin`.
Если в задании просят создать новую таблицу, необходимо написать отдельный файл миграции, где таблица будет пересоздана, и в нее будут добавлены тестовые данные. Тесты должны быть написаны с учетом этих данных
Нужно написать отдельный файл с тестами, по тесту на каждый уникальный вывод `NOTICE`. Все тесты должны быть обернуты в `BEGIN ... ROLLBACK`
Триггер и функция должны быть определены в одном файле, примеры привел
Поясняющих комментариев должно быть по минимому, либо вообще нет. Нельзя писать `-- File: название_файла.sql`
`DROP FUNCTION IF EXISTS` не нужно использовать при наличии `CREATE OR REPLACE FUNCTION`
В PostgreSQL plpgsql не поддерживаются спецификаторы формата типа %.2f, %s, %d. Доступен только один плейсхолдер — %.
