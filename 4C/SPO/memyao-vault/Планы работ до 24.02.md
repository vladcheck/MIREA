## Бекендер
Необходимо на основе UseCase от Аналитика оформить БД-шечку нашего проекта
Нужны таблицы:
- Ролей:
	- id
	- название
	- описание
- Пользователей:
	- id
	- тег пользвователя
	- ссылка на аватар
	- learning_rate (float)
	- interests (json)
	- accumulated_gradients (json)
	- tag_interactions (json):
	  default = {
		  like = 8.0
		  comment = 15.0
		  view = 1
		  dislike = -20
		  share = 25
		}
	- total_interactions (Int)
	- interests_embeding (Array float)
	- last_updated (DateTime)
- Постов:
	- id
	- пользователь
	- название
	- описание
	- статья
	- ссылка на видос (мем за минту)
	- ссылка на сам пост
	- теги
	- tags_embeding (Array float)
	- likes 
	- dislikes
	- просмотры
	- счётчик поделившихся 
	- comments_count 
	- Время когда запостили
	- Время когда рассмотрели
	- Status (Json)
		default = {
			status = отклонено
			причина = чел кринж
		}
- Просмотров постов (Нужна чтоб трекать кто какие посты просмотрел и когда)
	- id
	- пользователь
	- пост
	- ip_address
	- user_agent (text)
	- viewed_at
- Реакция пользователя на пост (Нужна для баланса вселенной и подсветки определённой кнопки при наступлении на пост, на который уже была поставлена реакция)
	- id
	- пользователь
	- пост
	- тип реакции (Список "лайк, дизлайк, нет реакции")
	- is_shared (bool)
	- is_commented (bool)
	- created_at (datetime)
	- updated_at (datetime)
- Комменты
	- id
	- пост
	- пользователь
	- контент (текст до 1.5к символов)
	- created_at (datetime)
	- updated_at (datetime)
	- is_active (bool)
	- parent (foreign key к родителю)
