# Контрольная работа №4

## Установка и запуск

1. Зайдите в папку с проектом, настройте окружение

```bash
cd TDSA/control_work_4
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

1. Выполните миграции базы данных (если не выполнены):

```bash
alembic upgrade head
```

Для запуска приложения:

```bash
uvicorn src.main:app --reload
```

Документация OpenAPI будет доступна по адресу `http://localhost:8000/docs`.

## Тестирование

В проекте реализованы модульные асинхронные тесты, которые покрывают основные сценарии (создание, получение, удаление), а также кастомные обработчики ошибок.
Запустить тесты:

```bash
pytest tests/
```
