# Контрольная работа №4

## Установка и запуск

1. Перейдите в папку проекта:

   ```bash
   cd TDSA/control_work_4
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Выполните миграции базы данных (если не выполнены):

   ```bash
   alembic upgrade head
   ```

5. Для запуска приложения:

   ```bash
   uvicorn src.main:app --reload
   ```

   Документация OpenAPI будет доступна по адресу `http://localhost:8000/docs`.

## Тестирование

В проекте реализованы модульные асинхронные тесты, которые покрывают основные сценарии (создание, получение, удаление), а также кастомные обработчики ошибок.
Запустить тесты:

```bash
pytest tests/
```
