# 0001: Стек mirea-mcp — Python + FastMCP (amend: заменяет TS + pnpm)

~~`mirea-mcp` пишется на TypeScript, запускается на Node, пакетный менеджер — pnpm, протокол — официальный `@modelcontextprotocol/sdk`.~~ **Amend (после рекон-скаута):** `mirea-mcp` пишется на Python (>=3.11) с FastMCP, пакетный менеджер — `uv`. Глоссарий и доменные термины — русские; имена инструментов английские, descriptions русские, соответствие терминам — таблица в README.
