# 0002: Разделение источников данных — СДО канон по текущему, Пульс по посещаемости и расписанию, ЛКС вне MCP

Канонический источник текущих учебных данных (дисциплины семестра, задания, дедлайны, баллы) — СДО (`online-edu.mirea.ru`, Moodle REST: токен из `login/token.php`, функции вида `core_enrol_get_users_courses`, `gradereport_user_get_grade_items`). Пульс (`pulse.mirea.ru`) — источник посещаемости (отметки по занятиям, баллы за посещение по виду занятия), расписания, данных группы и сводки БРС; у него JSON API за Keycloak SSO, контракт reverse-engineered и задокументирован в OSS-клиенте `daftrent/pymirea`. ЛКС исключён из scope MCP: это портал-витрина (документы, ссылки на ресурсы), автоматизировать там нечего.

**Status**: accepted

**Considered Options**: читать посещаемость из ЛКС (отвергнуто — она там не живёт: по п. 5.4 Положения о БРС посещаемость фиксирует Пульс; первоначальная версия этого ADR опиралась на ошибочную сводку и заменена); клиент ЛКС «на всякий случай» (отвергнуто — мёртвый код против шестимесячной поддерживаемости).

**Consequences**: два живых клиента (СДО, Пульс) вместо трёх; SSO-аутентификация Пульса — в ADR-0004.
