# 0003: Базовая линия mirea_plan — пороги 40/60, 75 % проверенных работ, дисциплина закрыта — исключить

Инструмент `mirea_plan` (что посетить / что сдать / что можно пропустить) считает цель по дисциплине так: зачёт — СБ ≥ 40 и ≥ 75 % проверенных работ; экзамен — СБ ≥ 60 и ≥ 75 % проверенных работ. Работа со 0 баллами считается проверенной; непроверенной — только отсутствующая. Критерии выполнены — дисциплина исключается из рекомендаций до конца семестра. Числа 40/60/75 % — не произвольны: это шкала перевода СБ в оценку и допуск к семестровому контролю из действующего Положения о БРС (СМКО 8.5.1/03.П.72-26), зафиксированного в `docs/normative-acts/`.

Параметры БРС меняются на семестр нормативными актами (БМАКС, распределение по категориям БТК/БП/БСК/БТД/БД/БДОП), поэтому в MCP они не хардкодятся: семестр начинается с выгрузки параметров из акта в конфиг `brs-semester.json`. Дисциплины наполняют категории разными работами, но сумма баллов одинакова — инструмент опирается на фактические работы из СДО, а не на шаблон.

**Status**: accepted

**Consequences**: при выходе нового Положения о БРС `brs-semester.json` обновляется сверкой с `docs/normative-acts/CHANGELOG.md`. Автоматический парсинг PDF актов не делается (хрупко); ручная сверка — осознанный trade-off.
