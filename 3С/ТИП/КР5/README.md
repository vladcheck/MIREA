# Express Voting System

## Описание проекта

Это REST API приложение для системы голосования, разработанное на Express.js. Приложение позволяет:

- Голосовать за различные варианты
- Просматривать результаты голосования в реальном времени
- Добавлять и удалять варианты для голосования
- Сбрасывать результаты голосования
- Администрировать систему через веб-интерфейс

## Технологии

- Node.js
- Express.js
- HTML/CSS/JavaScript (фронтенд)
- In-memory data store (для демонстрации)

## Доступные эндпоинты

### Голосование

- GET /api/votes - получить все голоса
- GET /api/votes/results - получить результаты голосования
- POST /api/votes - голосовать за вариант (body: { optionId: number })
- POST /api/votes/reset - сбросить все голоса (только для тестирования)

### Варианты

- GET /api/options - получить все варианты
- GET /api/options/:id - получить вариант по ID
- POST /api/options - создать новый вариант (body: { text: string })
- DELETE /api/options/:id - удалить вариант

## Веб-интерфейс

Приложение включает простой веб-интерфейс для взаимодействия с API:

http://localhost:3000/ - главная страница с формой голосования
Страница отображает доступные варианты, результаты голосования и административные функции
